# 本草收藏直播台

把源码交给自己的 AI 编程智能体，按个人需求改造角色、声音、互动规则、记忆和界面。

这是供其他 Windows 电脑试用的初步测试版。你可以先描述“现在怎样、希望怎样、怎样算改好了”，再让智能体阅读工程、修改并验证。入门模板见 [交给你的智能体](00-先读我：交给你的智能体.txt)。

## 下载与启动

到 [测试版 Release](https://github.com/bencao-lab/bencao-live-studio-public/releases/tag/v0.1.0-test.1) 下载“bencao-live-studio-windows-test.zip”，完整解压后打开“直播台/本草收藏数字人直播台.exe”。

这是解压运行的测试包。需要 Windows x64、Microsoft Edge WebView2 Runtime。接收抖音互动还需要安装在系统标准路径的 Google Chrome。使用自己的数字人、对话和语音服务账号，具体操作见 [使用说明](使用说明.txt)。第三方服务可能收费。

## 交给智能体继续开发

在 AI 编程工具中打开项目文件夹，先阅读 [开发交接](给智能体的开发交接.txt)。源码位于“源码”，本机接收服务位于“接收服务”，播放页面位于“播出资源”。每次提出一个明确需求并验证实际行为。

Git 仓库保存源码、青蒿演示图、构建脚本与说明。运行依赖随 Release 提供，源码克隆后的还原方法见 [依赖还原](依赖还原.md)。

个人密钥、Cookie、上传绑定和观众记录保存在本机用户数据目录。提供工程给云端智能体时，请排除这些数据。

## 验证范围

开发者已完成本机 --check、密钥隔离、本地服务接口和登录脚本加密存储检查。开发者侧已有 BreezeBlue 试听和真实礼物接收记录。

其他 Windows 电脑、全新用户登录到上传播出的完整流程、长时间运行和停止后的云端计费仍待验证。其他 TTS 保持实验性状态。
