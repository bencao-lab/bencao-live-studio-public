先确认任务
请围绕使用者当前提出的需求修改。保持配置与用户数据独立，不加入其他工程的绝对路径、预置账号或共享密钥。
本包包含可编辑源码和运行依赖。主程序为 Windows x64、C# WinForms，使用系统 .NET Framework 编译器；按现有 C# 语法版本编写，不直接使用现代 .NET 专有 API。

文件导航（均相对本包根目录）
源码/Studio.cs：窗口入口、分页、角色导入和基本播出控制。
源码/Performance.cs：声音设置、试听、直播间连接和互动入口。
源码/Preferences.cs、Brain.cs、QuickMoves.cs：角色规则、短期记忆与动作选择/节点。
源码/GiftBrain.cs、SpeechRules.cs：礼物队列、优先级和感谢表达。
源码/Audience.cs：观众记录和本机接收服务通信。
源码/Interaction.cs、ModelSettings.cs：对话/语音调用与服务设置。
源码/LiveView.cs、Vidu.cs、RoleUpload.cs：数字人会话、鉴权和图片上传。
源码/AppPaths.cs：外发版数据目录、端口、接收进程路径。
播出资源/index.html、live.js：WebView2 内的实时播放页面。
接收服务/server.mjs、douyin-source.mjs：本机 HTTP 接口、接收进程及礼物连送去重。
接收服务/douyin/browser-collector.mjs：浏览器事件采集适配。
接收服务/douyin/login.mjs、save-session.ps1、read-session.ps1：用户登录与本机加密存储。
接收服务/douyin/browser-engine：选用的第三方 DyHub 模块与依赖；保留来源及许可证。

本地构建
先关闭本包启动的直播台。在本包根目录打开 PowerShell，运行：
  .\构建.ps1
成功后输出仍为“直播台/本草收藏数字人直播台.exe”。不要复制出多个不同名字的程序。
需要 Windows 系统 .NET Framework 64 位 csc.exe；脚本会检查编译器和 WebView2 DLL 签名，不要为了构建通过而删掉签名检查。
如果本机执行策略阻止运行，说明具体原因并让使用者按其电脑管理要求处理，不要长期降低系统策略。
接收服务为 JavaScript，使用包内 node.exe，不需要重新编译；修改后须停止旧接收进程再启动新代码。

最小验证
1. 构建通过后运行本包 EXE，确认青蒿图、角色与声音、记忆与大脑等入口可用。
2. 可运行 EXE 的 --check 参数进行现有布局、动作节点及礼物队列检查，并核对进程退出码；它不连接真实直播或付费 API，也不代表完整业务验收。
3. 检查本次改动对应的行为、错误提示与停止路径；礼物须核对真实事件的送礼人、礼物名和数量，不能用弹幕文字假装收礼。
4. 声音、上传、实时数字人和真实登录需要使用者自己的账号；未实际测试的项目如实列出。

必须保持的边界
配置只在 %LOCALAPPDATA%/本草收藏直播台外发版；本机接收端口为 18769。
密钥和登录状态不写入源码、命令行参数、截图、日志或外发压缩包。不把整个个人配置目录上传给云端智能体。
图片、声音绑定、观众记忆和浏览器缓存属于用户数据。升级不得静默删除，不覆盖为开发者预设。
保持付费调用可取消、会话停止与客户端释放；正常关闭、断网和强制退出的云端费用停止仍需分别验证。
其他 TTS 保持“实验性，未实测”，直到对应服务有真实验收结果。
不要将第三方浏览器采集描述为抖音官方接口，也不要保证它永久可用。
再分发时保留第三方许可证；不要将厂商 SDK 声称为项目自行开源的代码。
